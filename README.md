## ✨ Возможности

- 🎨 **Генератор фавиконов** — создавайте фавиконы из эмодзи или текста
- 📱 **Генератор QR-кодов** — кастомизация цветов, форматов и размеров
- 🎲 **Генератор случайных чисел** — с историей, анимацией и экспортом
- 🎮 **Тетрис** — классическая игра с сохранением рекорда
- 🌍 **Полная локализация** — русский и английский языки
- 🔒 **Приватность** — все инструменты работают локально в браузере

## 🚀 Технологии

- **React 18** — современный UI
- **TypeScript** — типобезопасность
- **Vite** — быстрая сборка
- **Tailwind CSS** — стильный дизайн
- **React Router** — навигация
- **Canvas API** — генерация изображений
- **LocalStorage** — сохранение настроек

## 📦 Установка

```bash
# Клонировать репозиторий
git clone https://github.com/labqode-ID/freetools.git

# Перейти в папку проекта
cd freetools

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev

# Собрать production-версию
npm run build
